用户登录

通过账号密码完成身份认证，成功后返回 token 与用户基础信息。

请求参数

参数类型必填说明
accountstring是登录账号
passwordstring是登录密码

调用示例

POST /api/v1/auth/login

{
  "account": "admin",
  "password": "admin123"
}

错误码

  • 4010 用户名或密码错误
  • 4011 账号已被禁用
