# per_doc 界面原型

基于前端设计稿生成的静态 HTML 原型，用于**评审确认**，不是生产代码。

## 查看方式

直接双击 `index.html` 即可（无需服务器）。若需本地服务器：

```bash
cd per_doc/prototype
python -m http.server 8899
# 浏览器打开 http://localhost:8899/index.html
```

## 页面清单

| 文件 | 页面 | 路由 | 关键设计 |
|---|---|---|---|
| `index.html` | 原型导航 | - | 入口，含设计约定速查表 |
| `01-login.html` | 登录页 | `/login` | 居中卡片 380px，账号密码 + 记住我 + 忘记密码 |
| `02-home.html` | 文档库首页 | `/` | 卡片网格 + 分类分组 + 最近更新 + 统计 |
| `03-reader.html` | **阅读页（核心）** | `/s/:key` | 三栏：文档树 280px / 正文 900px / 目录 220px |
| `04-editor.html` | **编辑页（核心）** | `/s/:key/edit/:id` | 三栏：文档树 / Markdown 编辑器 / 实时预览 |
| `05-admin.html` | 后台管理 | `/manage` | 四个 Tab：文档库 / 用户 / 配置 / 日志（可点击切换） |
| `06-profile.html` | 个人设置 | `/profile` | 基本信息 / 修改密码 / 头像 |

## 设计语言

| 项 | 值 |
|---|---|
| 主色 | `#2f6feb`　成功 `#2ea121`　危险 `#d4380d`　警告 `#d89614` |
| 间距 | 8px 基准栅格：8 / 16 / 24 / 32 |
| 圆角 | 卡片与输入框 6px，按钮 4px |
| 字号 | 基础 14px，标题 20/16px，阅读正文 15px / 行高 1.75 |
| 导航栏 | 高 56px，白底 + 1px 底边框，吸顶 |
| 断点 | 768px（平板）　1024px（小屏桌面）　1440px（宽屏） |

## 交互说明

- **后台管理页**的四个 Tab 可点击切换（原生 JS，无框架依赖）
- 页面右下角为原型导航，左下角为跳转链接
- 所有链接均为占位符，无实际跳转

## 评审要点

请重点确认以下几项，确认后进入实现：

- [ ] 三个核心页面（首页 / 阅读 / 编辑）的**三栏比例**是否合适
- [ ] 阅读页是否需要**右侧目录栏**（可关闭）
- [ ] 编辑器采用「**分栏**」还是「**标签页切换**」模式
- [ ] 主色 `#2f6feb` 是否符合预期
- [ ] 后台是否保留「用户」管理（当前仅启用/禁用 + 重置密码，无角色）
- [ ] 移动端适配：侧边栏是否改为抽屉式

## 与最终实现的差异

原型是**静态示意**，落地时以下部分会不同：

- 字体、间距使用真实 CSS 变量（`assets/style.css` 中的 `:root`）
- Markdown 渲染改用 `markdown-it`，此处为手写静态 HTML
- 文档树改为 Vue 递归组件，拖拽排序用 `vuedraggable`
- 编辑器改为 CodeMirror 6 / Toast UI Editor，此处为原生 textarea
- UI 组件（表格、弹窗、提示）改用 Element Plus，此处为手写样式

**不要把 `prototype/` 下的代码直接复制到 `frontend/src/`。**
