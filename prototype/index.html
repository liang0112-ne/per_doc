per_doc 界面原型
基于前端设计稿生成。点击卡片进入对应页面。
技术栈：Vue 3 + TypeScript + Element Plus　设计语言：主色 #2f6feb / 8px 栅格 / 圆角 6px
01
登录页
/login　居中卡片 380px，账号密码 + 记住我 + 忘记密码
02
文档库首页
/　卡片网格 + 分类分组 + 最近更新 + 统计
03
阅读页（核心）
/s/:key　三栏：文档树 280px + 正文 900px + 右侧目录 220px
04
编辑页（核心）
/s/:key/edit/:id　三栏：文档树 + Markdown 编辑器 + 实时预览
05
后台管理
/manage　四个 Tab：文档库 / 用户 / 配置 / 日志
06
个人设置
/profile　基本信息 / 修改密码 / 头像上传
设计约定
主色#2f6feb　成功 #2ea121　危险 #d4380d　警告 #d89614
间距8px 基准栅格：8 / 16 / 24 / 32
圆角卡片与输入框 6px，按钮 4px
字号基础 14px，标题 20/16px，阅读正文 15px / 行高 1.75
断点768px（平板）　1024px（小屏桌面）　1440px（宽屏）
导航栏高 56px，白底 + 1px 底部边框，吸顶
