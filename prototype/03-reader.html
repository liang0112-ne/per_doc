用户登录

通过账号密码完成身份认证，成功后返回 token 与用户基础信息。同一账号连续失败 5 次将锁定 15 分钟。

请求参数

参数类型必填说明
accountstring是登录账号，可为用户名或邮箱
passwordstring是登录密码，长度 8–32 位
captchastring否开启验证码时必填

调用示例

POST /api/v1/auth/login
Content-Type: application/json

{
  "account": "admin",
  "password": "admin123"
}

成功响应

{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "expires_in": 7200,
    "user": {
      "member_id": 1,
      "account": "admin",
      "real_name": "管理员"
    }
  }
}

失败响应

{
  "code": 4010,
  "message": "用户名或密码错误"
}

错误码

错误码含义
4010用户名或密码错误
4011账号已被禁用
4290失败次数过多，账号已锁定
提示：登录成功返回的 token 需在后续请求中通过 Authorization: Bearer <token> 传递。

公式示例

令牌有效期计算：expires_in = 7200 秒。
